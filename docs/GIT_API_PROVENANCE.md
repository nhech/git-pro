# Git API attribution

Git Pro uses VS Code's stable APIs and the exported Git extension API v1. Optional methods are capability-detected.

The source declaration `src/types/git.d.ts` comes from [Microsoft VS Code 1.100.0](https://github.com/microsoft/vscode/blob/1.100.0/extensions/git/src/api/git.d.ts). Microsoft's original MIT notice is retained in the source declaration and [THIRD_PARTY_NOTICES.txt](../THIRD_PARTY_NOTICES.txt). The source declaration is excluded from the installation package.
