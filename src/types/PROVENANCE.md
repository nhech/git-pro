# Git API declaration provenance

`git.d.ts` is vendored unchanged from https://raw.githubusercontent.com/microsoft/vscode/1.100.0/extensions/git/src/api/git.d.ts on 2026-10-03. It is Microsoft's exported Git extension API v1 declaration for the minimum host baseline. Original MIT copyright notice retained; license text in `VSCODE-LICENSE.txt`.

Git Pro uses stable VS Code APIs plus this exported extension boundary; newer methods are capability-detected and are not required by the minimum supported host.
